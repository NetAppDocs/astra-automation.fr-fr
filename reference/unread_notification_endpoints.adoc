= Points de terminaison de notification non lue de l'API Astra (ACC)
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Trouvez les notifications qu'un utilisateur n'a pas encore lues et marquez-les comme lues.

L'API de notifications non lues fournit des informations sur les notifications qui n'ont pas été lues par un utilisateur donné et permet de les marquer comme lues.
