= Points de terminaison de ressources de l’API Astra (ACC) Kubernetes
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Consultez les ressources de l’API Kubernetes sur un cluster pour voir lesquelles sont prises en charge par Astra Control. Ces points de terminaison sont en lecture seule.

L'API Kubernetes API Resource fournit un accès en lecture seule aux ressources de l'API Kubernetes afin de filtrer celles prises en charge par Astra sur un cluster donné.
