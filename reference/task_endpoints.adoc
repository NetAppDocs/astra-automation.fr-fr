= Points de terminaison de tâches de l'API Astra (ACC)
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Consultez les tâches de longue durée suivies par Astra Control afin de pouvoir surveiller leur progression.

L'API de l'application Task permet d'accéder aux ressources de tâches gérées afin de représenter les tâches de longue durée.
